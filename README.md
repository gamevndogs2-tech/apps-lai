# LAI Apps Gallery

Bản demo tĩnh cho `apps.lai.id.vn`, giới thiệu các ứng dụng LAI theo kiểu phòng trưng bày.

- Mở `index.html` để xem. CSS và JavaScript nằm trong file này; icon nằm trong `assets/`.
- Các nút “Xem mô phỏng” mở hộp giới thiệu trong trang. Link truy cập sản phẩm sẽ được cập nhật khi có danh sách chính thức.

Thư mục này là repo Git cục bộ tạm thời; chưa cấu hình remote hoặc triển khai.
